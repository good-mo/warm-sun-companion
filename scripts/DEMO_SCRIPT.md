> 录制工具建议：OBS Studio / macOS QuickTime / Windows Xbox Game Bar。
> 前置：已按 [`DELIVERY.md`](../DELIVERY.md) 第 3 章完成 Docker Compose 部署，`frontend/src/config.local.js` 已填入魔珐星云凭证。

## 第一幕：启动与部署（0:00–0:40）

**口播**：这是一款基于魔珐星云具身交互智能 SDK 的 AI 数字人陪伴应用，面向老年群体。我们首先用 Docker Compose 一键部署。

1. 终端执行 `docker compose up -d --build`（展示构建过程，2 个容器）；
2. `docker compose ps` 展示 `warm-sun-frontend`（up）、`warm-sun-backend`（up）；
3. `curl -s http://localhost:8000/api/health` 返回 `{"status":"ok",...}`；
4. 浏览器打开 `http://localhost:5173`，展示暖阳陪伴主界面（数字人区 + 聊天区 + 记忆面板）。

## 第二幕：对话/驱动发起（0:40–1:40）

**口播**：现在发起一次对话，验证从"驱动发起 → 能力调用 → 结果呈现"的端到端流程。

1. 在输入框输入 **「今天天气不错，暖阳，陪我聊聊天吧」**；
2. 点击 **发送**；观察：
   - 状态条出现"思考中..."、输入区出现打字动画；
   - 数字人状态灯进入聆听/说话状态；
   - 数字人回复内容出现在聊天气泡中（可截图放大展示）。

## 第三幕：能力调用（1:40–2:40）

**口播**：暖阳具备长期记忆能力。告诉它一个喜好。

1. 输入 **「记住了，我喜欢喝绿茶」**，发送；
2. 右侧 **记忆面板** 出现新记忆，且被自动归类到 **「偏好」** 分组；
3. 刷新页面，再次打开记忆面板，记忆仍在（跨会话持久化验证）；
4. 可再补充一句 **「我老伴叫王建国」**，验证归入 **「家庭」** 分组。

## 第四幕：结果呈现（2:40–4:00）

**口播**：关怀模式的适老化效果，以及主动关怀。

1. 点击右上角 **关怀模式开关**（或按 `Alt+C`）：
   - 字体明显变大、对比度提升、按钮变大；
   - 数字人头部/调试按钮完整可见、无遮挡（验证近期修复）；
2. 展示记忆面板的分类分组（生日/姓名/偏好/健康/家庭），点击 **✕** 收起、展开；
3. 演示输入 **「你好」** 触发傍晚场景问候（依据 `care.js` 时段/节日场景），或展示系统提示气泡。

## 第五幕：收尾（4:00–4:30）

**口播**：总结——四大价值（陪伴不缺席、健康守护、不懂也能用、家人更放心）全部落地为可运行代码；MIT 开源、CI 通过、Docker 一键部署，评审方可直接复现。

1. 切回终端展示 `npm test` 通过（4 个用例）；
2. 镜头定格在关怀模式主界面。

## 录屏建议

- 分辨率 ≥ 1280×720，建议 1920×1080；
- 若需演示真实语音 ASR，请确保麦克风可用并在第二幕改用 **🎤 按住说话**；
- 若 SDK 凭证受限，演示可先展示界面/记忆/关怀模式等本地可验证能力，再展示数字人对话。
